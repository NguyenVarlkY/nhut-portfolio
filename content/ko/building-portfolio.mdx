# 포트폴리오 만들기

지금처럼 완성도 높은 포트폴리오를 만들기 위해 다음 요소에 집중했습니다:

## 1. 성능 최적화
**Next.js**는 서버 사이드 렌더링(SSR)과 정적 사이트 생성(SSG) 덕분에 페이지 로딩 속도가 매우 빠릅니다.

## 2. UI 디자인
**Tailwind CSS**를 사용하면 모든 기기에서 반응형으로 동작하는 현대적이고 일관된 UI 컴포넌트를 쉽게 만들 수 있습니다.

## 3. 사용자 경험(UX)
**AI 챗봇**, **다크 모드**, **PDF 다운로드**를 추가해 방문자가 제 프로필과 가장 자연스럽게 상호작용할 수 있도록 했습니다.
