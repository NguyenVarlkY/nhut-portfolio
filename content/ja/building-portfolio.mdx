# ポートフォリオの構築

現在のような完成度の高いポートフォリオを作るために、次の点に注力しました：

## 1. パフォーマンスの最適化
**Next.js** はサーバーサイドレンダリング（SSR）と静的サイト生成（SSG）により、非常に高速なページ読み込みを実現します。

## 2. UI デザイン
**Tailwind CSS** を使えば、あらゆるデバイスでレスポンシブに動作する、モダンで統一感のある UI コンポーネントを簡単に作れます。

## 3. ユーザー体験（UX）
**AI チャットボット**、**ダークモード**、**PDF ダウンロード**を追加し、訪問者が私のプロフィールに最も自然な形で触れられるようにしました。
