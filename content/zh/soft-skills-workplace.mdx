# 职场软技能：工程师成功的关键

许多年轻工程师只专注于技术，却忘了 **90% 的工作是与人打交道**，写代码只占 10%。软技能不会自然而然地出现，需要有意识地刻意练习。

## 1. 沟通（Communication）

### 1.1 把复杂问题讲简单
优秀的工程师必须能把复杂的技术问题传达给 **非专业人士**（利益相关者、PM、业务方）。

- 避免行话：用“把系统拆成更易管理的小部分”代替“重构微服务”。
- 使用示例、图片和生活中的类比。
- 关注 **结果** 和 **业务价值**，而不是技术细节。

### 1.2 书面沟通
- 编写目标明确、带有完成标准的任务。
- 以建设性的态度做代码评审。
- 将决策写成文档（ADR），让后来者明白“为什么”。

## 2. 主动性（Proactiveness）

- **主动承担工作** 并提出解决方案，而不是等着别人分配。
- 遇到问题时，提出 **2-3 个方案并附上建议**，而不是只问“怎么办？”。
- 主动向团队同步进度，不要等别人来问。
- 着眼未来：预判风险并提前准备。

## 3. 冲突解决（Conflict Resolution）

- 以 **文明** 的方式解决团队中的冲突。
- 关注 **工作和问题**，而不是 **个人**。
- 在反驳之前，先倾听并理解对方的观点。
- 寻找共识：“我们的问题是什么？对双方来说最好的解决方案是什么？”
- 如果无法自行解决，就私下沟通，不要在公开场合争执。

## 4. 时间管理与坚持

- 按影响程度（Impact）和紧急程度（Urgency）安排工作优先级。
- 懂得在适当的时候对不合理的要求说“不”。
- 坚持长期目标，不要因眼前的困难而气馁。

> *“软技能是最难学的，却也是回报最高的。”*
