# Das Portfolio bauen

Für ein so professionelles Portfolio wie das aktuelle habe ich mich auf drei Dinge konzentriert:

## 1. Performance
**Next.js** sorgt dank Server-Side Rendering (SSR) und Static Site Generation (SSG) für extrem schnelle Ladezeiten.

## 2. Oberflächendesign
Mit **Tailwind CSS** lassen sich moderne, einheitliche UI-Komponenten bauen, die auf jedem Gerät responsiv sind.

## 3. User Experience (UX)
Ein **KI-Chatbot**, ein **Dark Mode** und ein **PDF-Download** sorgen dafür, dass Besucher möglichst natürlich mit meinem Profil interagieren können.
