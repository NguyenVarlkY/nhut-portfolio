# Die Kunst des Prompt Engineering & systemisches Denken

KI ersetzt keine Engineers, aber Engineers, die KI zu nutzen wissen, ersetzen die, die es nicht können. Prompt Engineering ist eine Fähigkeit des systemischen Denkens.

## Eine wirksame Prompt-Formel (C.O.R.E)
* **C - Context:** Was ist der Kontext? Für wen ist die Antwort?
* **O - Objective:** Was genau ist das Ziel? (z. B. Code schreiben, debuggen, ein Konzept erklären).
* **R - Role:** Welche Rolle soll die KI einnehmen? (Senior Engineer, Architect, Security Expert).
* **E - Expectations:** Welches Ausgabeformat erwartest du? (Code, Markdown, JSON, Schritt-für-Schritt-Erklärung).

## In der Praxis
Statt zu fragen „Wie programmiere ich eine API?“, frag lieber:
> „Entwirf als Senior Backend Engineer einen REST-API-Endpunkt zur Verwaltung von Users mit Spring Boot. Wende Clean Architecture an, nutze Bean Validation für die Validierung und behandle Fehler zentral mit @ControllerAdvice. Der Code muss Unit-Tests mit JUnit 5 enthalten.“

## Die Kernhaltung
Prompt Engineering bedeutet im Grunde, **das Problem logisch zu zerlegen (Decomposition)**, damit die KI es verstehen und umsetzen kann. Diese Fähigkeit ist nur dann wirklich stark, wenn du solide Grundlagen hast (Betriebssysteme, Datenbanken, Netzwerke).
