# Nghệ thuật Prompt Engineering & Tư duy hệ thống

AI không thay thế kỹ sư, nhưng kỹ sư biết dùng AI sẽ thay thế kỹ sư không biết. Prompt Engineering là một kỹ năng tư duy hệ thống.

## Công thức Prompt hiệu quả (C.O.R.E)
* **C - Context:** Ngữ cảnh là gì? Ai là đối tượng nhận câu trả lời?
* **O - Objective:** Mục tiêu cụ thể là gì? (Ví dụ: viết code, debug, giải thích concept).
* **R - Role:** Đóng vai gì? (Senior Engineer, Architect, Security Expert).
* **E - Expectations:** Định dạng kết quả mong muốn? (Code, Markdown, JSON, giải thích từng bước).

## Ứng dụng thực tế
Thay vì hỏi: "Làm sao để code API?", hãy hỏi:
> "Với tư cách là một Senior Backend Engineer, hãy thiết kế một REST API endpoint để quản lý Users với Spring Boot. Hãy áp dụng Clean Architecture, bao gồm validation bằng Bean Validation và xử lý lỗi tập trung bằng @ControllerAdvice. Code phải có unit test với JUnit 5."

## Tư duy cốt lõi
Prompt Engineering thực chất là việc bạn **phân rã bài toán (decomposition)** một cách logic để AI có thể hiểu và thực thi. Kỹ năng này chỉ mạnh mẽ khi bạn đã vững kiến thức nền tảng (OS, Database, Networking).
