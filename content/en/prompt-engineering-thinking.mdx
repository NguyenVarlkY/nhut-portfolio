# The Art of Prompt Engineering & Systems Thinking

AI won't replace engineers, but engineers who know how to use AI will replace those who don't. Prompt engineering is a systems-thinking skill.

## An effective prompt formula (C.O.R.E)
* **C - Context:** What is the context? Who is the answer for?
* **O - Objective:** What exactly is the goal? (e.g. writing code, debugging, explaining a concept).
* **R - Role:** What role should the AI play? (Senior Engineer, Architect, Security Expert).
* **E - Expectations:** What output format do you want? (Code, Markdown, JSON, step-by-step explanation).

## In practice
Instead of asking "How do I code an API?", ask:
> "As a Senior Backend Engineer, design a REST API endpoint for managing Users with Spring Boot. Apply Clean Architecture, include validation with Bean Validation, and centralize error handling with @ControllerAdvice. The code must include unit tests with JUnit 5."

## The core mindset
Prompt engineering is really about **decomposing the problem** logically so the AI can understand and execute it. This skill is only powerful when you already have solid fundamentals (OS, databases, networking).
