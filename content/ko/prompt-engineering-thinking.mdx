# 프롬프트 엔지니어링의 기술과 시스템적 사고

AI가 엔지니어를 대체하지는 않지만, AI를 쓸 줄 아는 엔지니어는 그렇지 못한 엔지니어를 대체할 것입니다. 프롬프트 엔지니어링은 시스템적 사고 능력입니다.

## 효과적인 프롬프트 공식 (C.O.R.E)
* **C - Context:** 맥락은 무엇인가? 답변을 받는 대상은 누구인가?
* **O - Objective:** 구체적인 목표는 무엇인가? (예: 코드 작성, 디버깅, 개념 설명).
* **R - Role:** 어떤 역할을 맡길 것인가? (Senior Engineer, Architect, Security Expert).
* **E - Expectations:** 원하는 결과 형식은? (코드, Markdown, JSON, 단계별 설명).

## 실전 적용
"API는 어떻게 코딩하나요?"라고 묻는 대신 이렇게 물어보세요:
> "시니어 백엔드 엔지니어로서 Spring Boot로 Users를 관리하는 REST API 엔드포인트를 설계해 주세요. Clean Architecture를 적용하고, Bean Validation을 이용한 검증과 @ControllerAdvice를 이용한 중앙 집중식 오류 처리를 포함해 주세요. 코드에는 JUnit 5 단위 테스트가 있어야 합니다."

## 핵심 사고방식
프롬프트 엔지니어링의 본질은 AI가 이해하고 실행할 수 있도록 **문제를 논리적으로 분해**(decomposition)하는 것입니다. 이 능력은 기초 지식(OS, 데이터베이스, 네트워킹)이 탄탄할 때 비로소 강력해집니다.
