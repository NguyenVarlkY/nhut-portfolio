# 職場のソフトスキル：エンジニアの成功の鍵

多くの若手エンジニアは技術にばかり集中し、**仕事の 90% は人と働くことで、コードを書くのは 10% にすぎない** ことを忘れがちです。ソフトスキルは自然に身につくものではなく、意識的に鍛える必要があります。

## 1. コミュニケーション（Communication）

### 1.1 複雑な問題をシンプルに伝える
優れたエンジニアは、複雑な技術的課題を **専門外の人**（ステークホルダー、PM、ビジネス側）に伝えられなければなりません。

- 専門用語を避ける：「マイクロサービスをリファクタリングする」ではなく「システムを管理しやすい小さな部分に分ける」。
- 例や図、身近なたとえを使う。
- 技術的な詳細ではなく、**成果** と **ビジネス価値** に焦点を当てる。

### 1.2 文章でのコミュニケーション
- 目的と完了条件が明確なタスクを書く。
- 建設的な姿勢でコードレビューを行う。
- 後から来た人が「なぜ」を理解できるよう、意思決定を文書化する（ADR）。

## 2. 主体性（Proactiveness）

- 仕事を割り振られるのを待つのではなく、**自ら仕事を引き受け**、解決策を提案する。
- 問題にぶつかったら「どうすればいいですか？」と聞くだけでなく、**2〜3 つの解決策と推奨案** を示す。
- 聞かれる前に、自分から進捗をチームに共有する。
- 先を見据える：リスクを予測し、前もって備える。

## 3. 対立の解決（Conflict Resolution）

- チーム内の対立は **冷静かつ礼儀正しく** 解決する。
- **個人** ではなく、**仕事と問題** に焦点を当てる。
- 反論する前に、相手の視点に耳を傾けて理解する。
- 共通点を探す：「私たちの問題は何で、双方にとって最善の解決策は何か？」
- 自分たちで解決できない場合は、人前で言い争わず、個別に話し合う。

## 4. 時間管理と粘り強さ

- 影響度（Impact）と緊急度（Urgency）で仕事に優先順位を付ける。
- 不適切な依頼には、しかるべきタイミングで「ノー」と言えるようにする。
- 長期的な目標を粘り強く追い、目先の困難であきらめない。

> *「ソフトスキルは最も学ぶのが難しいが、最も高い報酬をもたらしてくれる。」*
