# L'art du prompt engineering et la pensée systémique

L'IA ne remplacera pas les ingénieurs, mais les ingénieurs qui savent utiliser l'IA remplaceront ceux qui ne le savent pas. Le prompt engineering est une compétence de pensée systémique.

## Une formule de prompt efficace (C.O.R.E)
* **C - Context :** quel est le contexte ? À qui s'adresse la réponse ?
* **O - Objective :** quel est l'objectif précis ? (par exemple : écrire du code, déboguer, expliquer un concept).
* **R - Role :** quel rôle l'IA doit-elle jouer ? (Senior Engineer, Architect, Security Expert).
* **E - Expectations :** quel format de résultat attendez-vous ? (code, Markdown, JSON, explication pas à pas).

## En pratique
Au lieu de demander « Comment coder une API ? », demandez plutôt :
> « En tant que Senior Backend Engineer, conçois un endpoint REST API pour gérer des Users avec Spring Boot. Applique la Clean Architecture, ajoute une validation avec Bean Validation et une gestion centralisée des erreurs avec @ControllerAdvice. Le code doit comporter des tests unitaires avec JUnit 5. »

## L'état d'esprit essentiel
Le prompt engineering consiste en réalité à **décomposer le problème (decomposition)** de manière logique pour que l'IA puisse le comprendre et l'exécuter. Cette compétence n'est vraiment puissante que si vous maîtrisez déjà les fondamentaux (OS, bases de données, réseaux).
