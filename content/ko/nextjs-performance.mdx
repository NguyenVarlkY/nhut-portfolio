# Next.js 성능 최적화

Next.js는 이미 빠르지만, 설정 방법을 모르면 의도치 않게 애플리케이션을 느리게 만들 수 있습니다. 제가 적용하는 기법은 다음과 같습니다.

## 1. 이미지 최적화 (next/image)
`next/image` 컴포넌트 사용은 필수입니다. 이 컴포넌트는 자동으로:
- 기기에 맞게 이미지 크기를 조정합니다.
- 뷰포트 밖의 이미지를 지연 로딩합니다.
- 브라우저가 지원하면 WebP 형식으로 변환합니다.

## 2. 폰트 최적화
`next/font`를 사용해 폰트를 자동으로 최적화하고 레이아웃 이동(CLS - Cumulative Layout Shift)을 방지하세요.

## 3. 데이터 패칭 전략
* **Static Site Generation (SSG):** 자주 바뀌지 않는 콘텐츠용(예: 홈페이지, 블로그).
* **Incremental Static Regeneration (ISR):** 전체를 다시 빌드하지 않고 주기적으로 갱신해야 하는 콘텐츠용.
* **Server-Side Rendering (SSR):** 요청마다 실시간으로 갱신되어야 하는 데이터일 때만 사용.

```javascript
// ISR 예시
export async function getStaticProps() {
  const posts = await getPosts();
  return {
    props: { posts },
    revalidate: 60, // 60초마다 다시 생성
  };
}
```

병목이 정확히 어디에 있는지 알려면 항상 Lighthouse로 측정하세요!
