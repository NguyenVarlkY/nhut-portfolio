# 提示词工程的艺术与系统思维

AI 不会取代工程师，但会用 AI 的工程师会取代不会用的工程师。提示词工程是一种系统思维能力。

## 高效提示词公式（C.O.R.E）
* **C - Context：** 背景是什么？谁是答案的接收者？
* **O - Objective：** 具体目标是什么？（例如：写代码、调试、解释概念）。
* **R - Role：** 让它扮演什么角色？（Senior Engineer、Architect、Security Expert）。
* **E - Expectations：** 期望的输出格式？（代码、Markdown、JSON、分步讲解）。

## 实际应用
与其问“怎么写一个 API？”，不如这样问：
> “作为一名资深后端工程师，请用 Spring Boot 设计一个管理 Users 的 REST API 端点。采用 Clean Architecture，使用 Bean Validation 做校验，并用 @ControllerAdvice 集中处理错误。代码需要附带 JUnit 5 单元测试。”

## 核心思维
提示词工程的本质，是把 **问题按逻辑拆解（decomposition）**，让 AI 能够理解并执行。只有当你具备扎实的基础知识（操作系统、数据库、网络）时，这项技能才会真正强大。
