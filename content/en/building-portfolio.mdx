# Building the Portfolio

To get a portfolio as polished as the current one, I focused on three things:

## 1. Performance
**Next.js** makes pages load extremely fast thanks to Server-Side Rendering (SSR) and Static Site Generation (SSG).

## 2. Interface design
With **Tailwind CSS**, I can easily build modern, consistent UI components that are responsive on every device.

## 3. User experience (UX)
Adding an **AI chatbot**, **dark mode**, and **PDF download** lets visitors interact with my profile in the most natural way.
