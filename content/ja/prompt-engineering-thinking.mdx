# プロンプトエンジニアリングの技術とシステム思考

AI がエンジニアを置き換えることはありませんが、AI を使いこなすエンジニアは、使えないエンジニアを置き換えるでしょう。プロンプトエンジニアリングはシステム思考のスキルです。

## 効果的なプロンプトの公式（C.O.R.E）
* **C - Context：** 文脈は何か？ 回答を受け取るのは誰か？
* **O - Objective：** 具体的な目的は何か？（例：コードを書く、デバッグする、概念を説明する）。
* **R - Role：** どんな役割を演じさせるか？（Senior Engineer、Architect、Security Expert）。
* **E - Expectations：** 期待する出力形式は？（コード、Markdown、JSON、ステップごとの説明）。

## 実践での使い方
「API はどうやって書くの？」と聞く代わりに、こう聞きましょう：
> 「シニアバックエンドエンジニアとして、Spring Boot で Users を管理する REST API エンドポイントを設計してください。Clean Architecture を適用し、Bean Validation による検証と @ControllerAdvice による集中的なエラー処理を含めてください。コードには JUnit 5 のユニットテストを付けてください。」

## 核となる考え方
プロンプトエンジニアリングの本質は、AI が理解して実行できるように **問題を論理的に分解（decomposition）** することです。このスキルは、基礎知識（OS、データベース、ネットワーク）がしっかりしていてこそ力を発揮します。
